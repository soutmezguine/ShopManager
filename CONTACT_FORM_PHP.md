# PHP Contact Form for Shop Manager Leads API

Use this example on your external PHP website to submit leads securely to the Shop Manager `/leads/contact` endpoint.

## Requirements

- Shop Manager app must be running and reachable from your PHP site.
- Generate a lead form token from the admin settings panel in Shop Manager.
- Replace `YOUR_LEAD_FORM_TOKEN_HERE` with the token generated by the admin.
- Replace `https://your-shopmanager-site.example.com/leads/contact` with your application URL.

## HTML Form

```php
<?php
$leadFormToken = 'YOUR_LEAD_FORM_TOKEN_HERE';
?>

<form method="POST" action="">
  <div>
    <label for="name">Name</label>
    <input id="name" name="name" type="text" required />
  </div>

  <div>
    <label for="phone_number">Phone</label>
    <input id="phone_number" name="phone_number" type="tel" />
  </div>

  <div>
    <label for="email">Email</label>
    <input id="email" name="email" type="email" required />
  </div>

  <div>
    <label for="message">Message</label>
    <textarea id="message" name="message" rows="5" required></textarea>
  </div>

  <input type="hidden" name="token" value="<?php echo htmlspecialchars($leadFormToken, ENT_QUOTES); ?>" />
  <button type="submit" name="submit">Send Message</button>
</form>
```

## PHP Submission Code

```php
<?php
if (isset($_POST['submit'])) {
    $apiUrl = 'https://your-shopmanager-site.example.com/leads/contact';

    $postData = [
        'name' => $_POST['name'] ?? '',
        'phone_number' => $_POST['phone_number'] ?? '',
        'email' => $_POST['email'] ?? '',
        'message' => $_POST['message'] ?? '',
        'token' => 'YOUR_LEAD_FORM_TOKEN_HERE'
    ];

    $ch = curl_init($apiUrl);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($postData));
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        'Accept: application/json',
        'Content-Type: application/x-www-form-urlencoded'
    ]);

    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        $error = 'Unable to send contact request: ' . $curlError;
    } elseif ($httpCode !== 200 && $httpCode !== 201) {
        $error = "Submission failed with HTTP status $httpCode";
    } else {
        $success = 'Your message has been sent successfully.';
    }
}
?>

<?php if (!empty($error)): ?>
  <div class="error"><?php echo htmlspecialchars($error, ENT_QUOTES); ?></div>
<?php endif; ?>

<?php if (!empty($success)): ?>
  <div class="success"><?php echo htmlspecialchars($success, ENT_QUOTES); ?></div>
<?php endif; ?>
```

## Notes

- Keep the token private and only use it on trusted websites.
- If the token is regenerated in the admin panel, update the PHP form with the new value.
- The API also accepts the token in the `X-Lead-Form-Token` HTTP header if you prefer not to include it in the form body.
